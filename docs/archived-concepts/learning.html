DIRECTION 03 / LEARNING FROM EXPERIENCE

Learn the rule.
Then adapt.

Can an AI learn how an unfamiliar environment works from a few experiments—and revise its expectations when the rules change? Small interactive worlds let us test this directly.

THE PROBLEM

Experience should change a model.

An agent can describe gravity yet still repeat a failed action. We want to separate recalling a familiar explanation from learning something useful through interaction.

THE RESEARCH QUESTION

Which experiment should it try?

Use a small world with hidden forces. Compare deliberate experiments with random exploration and a fixed policy. Then change a force or surface property and see whether the agent notices and adapts.

THE REUSABLE OUTPUT

A testbed for adaptive reasoning.

A proposed benchmark with actions, observations, predictions, failures, and recovery attempts. Optional human playthroughs in VR could provide comparison strategies. Simulation results would not establish new laws of nature.

WHAT WOULD COUNT AS PROGRESS?

Better predictions.
Fewer trials.

Measure predictions on unseen layouts, the trials needed to adapt after a rule change, and performance on held-out rule families. Give each method the same observations and action budget. This tests adaptation by a pretrained agent; it does not demonstrate human-like development from scratch.

STARTING FROM EXISTING WORK

PHYRE already studies sample-efficient physical reasoning. Our proposed emphasis is choosing informative experiments and recovering after hidden rules change. We would compare with existing work before claiming a new benchmark contribution.
