A BOUNDED AGENT LOOP / ILLUSTRATIVE WORKFLOW

Start with something specific.

For example: why does light change direction near a star? Separate an established explanation from any proposed new hypothesis.

THE PURPOSE

Make the research legible.

Let people see what was tested, which predictions failed, and what remains uncertain. This is the lab’s publishing format, supporting the research directions rather than a separate consumer business.

THE OUTPUT

Evidence + visual explanation.

Share experiment designs, benchmark examples, sources, and revision history. A visual should help a reader inspect a result. It should never substitute for one.

A FIRST SMALL TEST

One explanation, bounded revisions.

Use an established physics question to test the publishing method. Render, inspect, and revise with explicit scientific checks. The light-bending illustration here is a style example, not research evidence.

WHAT WOULD MAKE IT USEFUL?

Do people build better intuition?

Compare the guide with a text explanation using a few new prediction questions. Measure comprehension and scientific errors before attempting autonomous daily publication.
